\problem{Numerical derivatives by finite differencing}
    Consider a continuously differentiable function $f: \mathbb{R} \to \mathbb{R}$.
    Based on evaluations at points $x_i$ with $x_{i+1} = x_{i} + \Delta x$, we 
    would like to approximate the derivative $f'_i \equiv \frac{df}{dx}(x_i)$.

    In the lecture, we have derived

    \begin{itemize}
        \item the first order forward difference formula
        \begin{equation}
                f'_i = \frac{f_{i+1} - f_{i}}{\Delta x} + \mathcal{O}(\Delta x)
        \end{equation}
        \item and the second order central difference formula
        \begin{equation}
            f'_i = \frac{f_{i+1} - f_{i-1}}{2 \Delta x} + \mathcal{O}(\Delta x^2)
        \end{equation}
    \end{itemize}

    based on Taylor expasion.

    \begin{enumerate}
        \item We would now like to derive a symmetric $4$-th order finite difference formula
        to approximate $f'_i$. Determine the coefficients $a$ and $b$ in the symmetric Ansatz
        \begin{equation}
            f'(x) = a \, (f(x + \Delta x) - f(x - \Delta x)) + b \, (f(x + 2 \Delta x) - 2 f(x - \Delta x)) + \mathcal{O}(\Delta x^4)
        \end{equation}
        to obtain a $4$-th order finite difference approximation of $f'(x)$ by Taylor expansion.
        \item Implement Python functions to calculate
        \begin{itemize}
            \item first order forward differencing formula
            \item second order central differencing formula
            \item symmetric fourth order differencing formula
        \end{itemize}
        You may pass the following inputs:
        \begin{itemize}
            \item the function to be differentiated
            \item the evaluation point
            \item $\Delta x$
        \end{itemize}
        We will call the result from the implementation of the finite difference formula $\hat{f}_i'$ from now on.
        \item Consider the function $f(x) = L(L(L(x)))$ where $L$ is the \textit{logistic map} $L(x) = 4x(1-x)$.
        \begin{itemize}
            \item Find the analytical derivative of $f$ by chain rule. \textit{Hint:} You don't need to carry out the multiplications.
            \item For $x_0 = 0.2$ and $\Delta x = \operatorname{np.logspace}(-15, -3, \text{num} = 200)$ calculate the error term $\text{err} = |\hat{f}_0' - f'_0|$ 
            for all three finite difference formulas. Plot the error term over $\Delta x$ in a double-logarithmic plot.
        \end{itemize}
        \item Where is the round-off error, where the truncation error dominant? Explain the behavior you observe.
    \end{enumerate}
